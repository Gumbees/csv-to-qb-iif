QuickBooks Web Connector

Pull data from QuickBooks Desktop using Web Connector

⬇️ Download QWC File
Setup Instructions:
  1. Download the QWC file above
  2. Open QuickBooks Desktop with your company file
  3. Open QuickBooks Web Connector (QBWC)
  4. Add the QWC file and use credentials: qbwc_user / password123
  5. Click "Sync Chart of Accounts" or "Sync QB Customers" buttons above
  6. Click "Update Selected" in QBWC to start sync
