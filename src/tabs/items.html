Step 3: Sync to QuickBooks via Web Connector

Important: Items are automatically synced when you run QuickBooks Web Connector. Make sure QuickBooks Desktop is open and click "Update Selected" in QBWC.

How it works:

  1. Extract items using the button above
  2. Open QuickBooks Desktop with your company file
  3. Open QuickBooks Web Connector
  4. Click "Update Selected" to sync items
  5. Items will be marked as synced automatically
